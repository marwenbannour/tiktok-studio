# 🎬 ستوديو التيكتوك

app Android (Flutter) تحضّرلك **سكريبت فيديو TikTok كامل بالدارجة التونسية** في ثواني، بالذكاء الاصطناعي.
تختار النوع والفكرة، والـAI يحضّرلك السكريبت ثانية بثانية، والكود، وخطوات التصوير والمونتاج، والـcaption والهاشتاڤات، ومعاها **Teleprompter** تقرا بيه وإنت تسجّل، و**تسجيل بالكاميرا** مباشرة في الـapp.

> الفكرة · السكريبت · الفيديو

---

## 🚀 شنوّة تعمل

- **حضّر:** اختار النوع (Dev AI · Football · معلومات · ضحك)، الفكرة (اختياري)، طريقة الظهور، والمدّة (15/20/30/45s). اضغط «حضّرلي الفيديو».
- **النتيجة:** سكريبت ثانية بثانية (الشاشة + النص + الصوت)، كود (للبرمجة)، خطوات التصوير والمونتاج، caption + هاشتاڤات + نصايح. تنجم:
  - تبدّل أي segment بيدّك ولا تخلّي الـAI يعاود يكتبو.
  - تنسخ (الصوت / الكود / الـcaption / الكل) ولا تشارك ولا تصدّر `.txt`.
  - تعلّمو ⭐ مفضّلة ولا ✅ تنشر، ولا تزيدو للبرنامج.
- **Teleprompter:** النص يتسكرولا وحدو (تتحكّم في السرعة والخط)، والشاشة تبقى محلولة. فيه زرّ 🎥 باش تسجّل بالكاميرا الأمامية والنص يبان قدّامك.
- **المحفوظات:** كل السكريبتات تتسجّل بلا حدّ (قاعدة SQLite على التليفون). **بحث** في العنوان والمحتوى، **فلترة** حسب النوع، و**المفضّلة**.
- **البرنامج:** برمج فيديوهاتك بالتاريخ والوقت، تابع الحالة (فكرة → تصوّر → تنشر)، وخذ **تذكير** وقت النشر.
- **الإعدادات:** مفتاح Ollama، الموديل، و**حدّ شهري للتوليد** (باش ما تخرجش على الميزانية).

---

## 📲 كيفاش تركّب الـapp على التليفون

1. خذ ملفّ `app-arm64-v8a-release.apk` (ولا `app-release.apk` اللي يمشي على أي تليفون).
2. ابعثو للتليفون: USB، Google Drive، WhatsApp لروحك…
3. في التليفون: «الملفّات» ← «التنزيلات» ← اضغط على الملفّ ← اسمح بالتثبيت من مصدر غير معروف.
4. كان يطلعلك **Google Play Protect** يحذّر، اضغط «More details» ← «Install anyway» (الـapp آمنة، برك مش من Play Store).

> يمشي على **Android 7.0 (API 24)** وما فوق.

---

## 🔑 مفتاح Ollama (مجّاني)

الـapp تستعمل **Ollama Cloud** باش يحضّر السكريبت (ما يخدمش بلا مفتاح).

1. ادخل لـ**ollama.com** واعمل compte.
2. في **Settings ← API Keys** اعمل مفتاح جديد وانسخو.
3. في الـapp: «الإعدادات» ← الصق المفتاح ← «سجّل المفتاح».
4. اختار الموديل:
   - **Gemma 4** 🆓 — مجّاني في الـfree plan (الافتراضي، باهي للبداية).
   - GPT-OSS / Qwen / DeepSeek — أقوى، أما يحتاجو **plan مدفوع ولا credits**.

> إذا الموديل تبدّل اسمو، لقى الأسماء الصحيحة في **ollama.com/search?c=cloud** واكتبو في خانة «موديل آخر».

---

## ⚠️ حاجات مهمّة

- **المفتاح هو فلوسك.** يتسجّل مشفّر على تليفونك برك (Android Keystore). ما تحطّوش في الكود، ما تبعثوش لحدّ، وما يبانش في تسجيل الشاشة وإنت تصوّر!
- حطّ **حدّ شهري** في «الإعدادات» باش ما تخرجش على الميزانية (الـapp تنبّهك عند 80% وتبلوكي كي توصل الحدّ).
- الـapp هذي لاستعمالك إنت. للنشر على Play Store للناس الكل، الأحسن server يخبّي المفتاح.

## 🧑‍💻 للمطوّر (build من الكود)

```
flutter pub get
flutter run                       # على جهاز مربوط
flutter build apk --release       # APK موقّع (يحتاج android/key.properties)
flutter build appbundle --release # AAB للـPlay Store
flutter test test/                # unit tests
flutter test integration_test/app_e2e_test.dart -d <device>   # e2e
```

**البنية:**
```
lib/main.dart                 ← الـapp + الـbottom bar + شاشة الإطلاق
lib/theme.dart                ← نظام الألوان (charte graphique)
lib/claude_api.dart           ← الاتصال بـOllama (/api/chat)
lib/prompts.dart              ← التعليمات اللي تمشي للـAI
lib/models.dart               ← VideoScript, Segment, PlannedVideo
lib/db/database.dart          ← قاعدة SQLite (drift) للمحفوظات
lib/storage.dart              ← المفتاح + الموديل + الحدّ + المحفوظات + البرنامج
lib/screens/                  ← حضّر، النتيجة، Teleprompter، تسجيل، المحفوظات، البرنامج، الإعدادات
lib/widgets/                  ← الأزرار والحلقات neon + الـprompter
```

> ملاحظة: الـclasses `ClaudeApi`/`ClaudeException` قعدو بأسماءهم (داخليا)، أما الـapp تخدم بـ**Ollama** مش Claude.

## 🩺 مشاكل معروفة

| المشكل | الحل |
|---|---|
| «زيد مفتاح الـAPI» | حطّ مفتاح Ollama في «الإعدادات» |
| «المفتاح موش صحيح ولا ما عندوش الحق» | عاود الصق المفتاح، ولا بدّل الموديل (يمكن يحتاج plan مدفوع) |
| «الموديل موش موجود» | اكتب الاسم الصحيح من ollama.com/search?c=cloud |
| «الرصيد كمل» / «برشا طلبات» | استنّى شوية، ولا زيد credits في ollama.com |
| «وصلت الحدّ الشهري» | بدّل الحدّ في «الإعدادات» |
| «ما فماش كونكسيون» | ثبّت في الإنترنت |
| «التطبيق غير متوافق» وقت التثبيت | ركّب نسخة `arm64-v8a` (تمشي مع أغلب التليفونات) |
